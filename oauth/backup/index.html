Workspace Backup Utility

An internal utility used to back up authorized Google Apps Script projects and perform technical integrity checks.

Purpose

The utility creates backup copies of Apps Script source code, records technical state information, and performs consistency checks for resources explicitly authorized by the user.

Google access

Access to Google Drive, Google Sheets and Google Apps Script is used only for backup, integrity verification and technical monitoring of resources available to the authorized user.

Data storage

Backup and technical files remain in the authorized user's Google Drive. This public website does not store OAuth tokens, project source code or the contents of operational Google Workspace files.
