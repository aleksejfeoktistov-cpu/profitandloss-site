Эта политика описывает обработку данных при использовании сайта Profit & Loss и внутренних служебных инструментов, работающих с Google Workspace.

Какие данные используются

Служебные инструменты могут получать доступ к Google Drive, Google Sheets и Google Apps Script-проектам, которые доступны авторизованному пользователю. Такой доступ используется только для резервного копирования, проверки целостности и технического мониторинга.

Как используются данные

  • для создания резервных копий исходного кода Apps Script;
  • для формирования технических реестров и контрольных статусов;
  • для проверки согласованности отдельных компонентов;
  • для диагностики технических ошибок.

Хранение

Резервные копии и технические файлы сохраняются в Google Drive авторизованного пользователя. Публичный сайт Profit & Loss не хранит OAuth-токены, исходный код Apps Script-проектов или содержимое рабочих Google-файлов.

Передача третьим лицам

Данные Google не продаются и не используются для рекламы. Они не передаются третьим лицам, кроме случаев, необходимых для работы инфраструктуры Google, через которую пользователь самостоятельно предоставляет доступ приложению.

Управление доступом

Пользователь может отозвать доступ в настройках безопасности своего Google-аккаунта. После отзыва служебные инструменты теряют возможность обращаться к соответствующим данным.

Контакты

По вопросам конфиденциальности используйте контактные данные разработчика, указанные на экране согласия Google OAuth.
